# Windows support

OptMem runs on native Windows in PowerShell; WSL is not required. Windows uses
the same append-only store format as Linux and macOS.

## Prerequisite

Python 3.7 or newer must be available through `py -3` or `python`:

```powershell
py -3 --version
```

## Install

```powershell
irm https://raw.githubusercontent.com/doeixd/OptMem/main/install.ps1 | iex
```

To inspect the installer first:

```powershell
irm https://raw.githubusercontent.com/doeixd/OptMem/main/install.ps1 -OutFile install-optmem.ps1
Get-Content .\install-optmem.ps1
powershell -ExecutionPolicy Bypass -File .\install-optmem.ps1
```

The installer downloads and validates:

```text
$HOME\.optmem\memo       Python tool
$HOME\.optmem\memo.cmd   Windows launcher
```

It then initializes `$HOME\.optmem\memory` and prints a copyable agent
instruction block. It also adds `$HOME\.optmem` to the user PATH and the
current PowerShell session, making `memo` available immediately, and registers
native tab completion in the current and future PowerShell sessions.
Re-running the installer updates the tool, launcher, and completion without
duplicating profile or PATH entries or changing memories and configuration.

## Connect an agent

From the repository the agent will work in:

```powershell
Set-Location C:\path\to\project
memo setup --create
```

This safely creates or updates managed OptMem instructions in both
`AGENTS.md` and `CLAUDE.md` while preserving all other content. It is
idempotent. Creation requires the explicit `--create` flag shown above;
without it, missing files are skipped. `--no-create` can state that safe
default explicitly in scripts. Pass explicit paths to target only selected
files:

```powershell
memo setup .\AGENTS.md
```

## Verify

```powershell
memo doctor
```

`doctor` shows the executable, Python version, current Git origin, active
scope, project/global store paths, and optional FFF status. It does not write
anything.

## Run commands

The installer makes the short command available:

```powershell
memo wake
memo note "first project memory"
memo --global note "true in every project"
memo recall --limit 5 --context 2 "deployment"
memo zoom --depth 3 0-255
```

The launcher path remains a reliable fallback:

```powershell
& "$HOME\.optmem\memo.cmd" doctor
```

Agent instructions generated by `memo init` use that fully qualified command,
so they work independently of PATH.

## Upgrade and uninstall

Update the CLI, launcher, PATH entry, and completion:

```powershell
memo upgrade
```

Remove those installed components:

```powershell
memo uninstall
```

Uninstall preserves `$HOME\.optmem\memory`, all project memories, and managed
blocks in connected agent instruction files. Open a new PowerShell window
afterward to remove the old command from that process's PATH. If permanently
retiring OptMem, remove its `OPTMEM:START`/`OPTMEM:END` blocks from
`AGENTS.md`, `CLAUDE.md`, or other connected instruction files. Delete the
memory directories separately only if you intentionally want to erase them.

## Shell completion

The installer enables completion automatically. Type `memo` and press Tab to
complete commands, flags, configuration names, and supported shell names.

To load the generated completion into a temporary PowerShell session manually:

```powershell
memo completion powershell | Out-String | Invoke-Expression
```

See [AGENT_SETUP.md](AGENT_SETUP.md) for the first agent session, memory
selection, recall, and subagent guidance.

FFF-powered typo-tolerant recall is optional and requires Python 3.10+:

```powershell
py -3 -m pip install fff-search
memo recall --fuzzy "aproximate memry"
```

Exact `memo recall <regex>` continues to work without FFF.

## Override scoping

To pin all commands to an explicit store instead of project/global scoping:

```powershell
$env:MEMORY_DIR = 'C:\path\to\memory'
memo wake
```

That assignment lasts for the current PowerShell process. Remove it with:

```powershell
Remove-Item Env:MEMORY_DIR
```

## Locking

On POSIX, OptMem uses `fcntl.flock`. On Windows it locks byte zero of the
shared `.lock` file with `msvcrt.locking` and waits with bounded backoff when
another process is writing. The file is opened without truncation, so
parallel agent sessions serialize their updates safely.

## Troubleshooting

- Script execution is disabled: use the `powershell -ExecutionPolicy Bypass
  -File` review-first command above, or use the `irm ... | iex` form.
- `memo` is not recognized: open a new PowerShell window or call
  `& "$HOME\.optmem\memo.cmd"` directly. Re-running the installer repairs a
  missing user PATH entry.
- Tab completion is missing: open a new PowerShell window or re-run the
  installer to repair the completion line in your user profile.
- The wrong store is active: run `memo doctor`, then check `MEMORY_DIR`, the
  current directory, and `Git origin`.
- Python opens the Microsoft Store: install Python from
  [python.org](https://www.python.org/downloads/windows/) or configure an
  existing Python so `py -3` works.
- Fuzzy recall fails: run exact recall, or reinstall `fff-search` with the same
  Python selected by the installer.
